# 模型、激励和黄金参考

- `model/`：真实部署YOLO26n的NCNN模型与上游许可说明，不是YOLO26 medium/large，也未擅自改权重。
- `input_300.jpg`：既有HTTP单图验收输入；PS按既定语义缩放/补边至320。
- `axis_vectors.txt.gz`：已通过的97报文公开接口激励，解压后SHA记录在来源清单。黄金应答来自冻结整数参考，不通过当前被测RTL临时生成。
- `reference/`：原实板固定输入C10/C20/C30整数与量化PL尾网、CPU FP32尾网输出。CPU与PL各有黄金结果，不强求两者逐值相等。

固定RGB320与参数在 `board/pl30/`，避免另复制一份。此处不包含完整训练集、训练过程或全量精度评估；实际验证范围见设计报告。
